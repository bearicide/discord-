# MATTBEAR Discord UI Asset Pack

Original SVG assets for Discord-adjacent community portals and dashboards.

## Includes
- 32 original SVG icons
- Discord-style dark backgrounds and subtle patterns
- UI fragments
- CSS design tokens and utilities
- searchable preview gallery
- mobile and reduced-motion support
- optional supplied MATTBEAR source image

Open `preview/index.html` to browse the pack.
